# Dice Rolling Game

A simple dice rolling game written in Python.

## Features

- The user chooses whether to roll the dice.
- The user selects how many dice to roll.
- The result of each die is displayed.
- The total of the dice is calculated.
- The program closes when the user enters `no`.

## How to Run

Run this command in the terminal:

```bash
python dice_rolling_game.py
